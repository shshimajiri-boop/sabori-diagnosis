# サボり方診断

10問でわかる、あなたの“サボり方タイプ”診断アプリ。会社・学校・バイトで「いるいる」となる全16タイプを、ちょっと毒舌に診断します。

## 特徴

- 10問×4択、1分で診断
- 全16タイプ（気配消し忍者 / 仮病海外旅行 / 締切ブースト待ち など）
- 結果は「特徴・よくある言い訳・バレやすい瞬間・周りからの見え方・改善アドバイス・相性」を表示
- 𝕏（Twitter）へのシェア・結果コピー機能
- PDF保存（印刷ダイアログから「PDFに保存」）
- スマホ最適化・ホーム画面に追加可能（PWA対応）

## 使い方

ブラウザで公開URL（GitHub Pages）を開くだけ。インストール不要・サーバー不要の単一HTMLアプリです。

`index.html` をダウンロードしてダブルクリックでも動作します。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS 一体型） |
| `icon.svg` | ホーム画面アイコン |
| `manifest.webmanifest` | PWA設定 |

## 注意

エンタメ目的の診断アプリです。いじっているのは「サボり方」だけで、人格を否定するものではありません。
